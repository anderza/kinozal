# Кинозал

Android-приложение для просмотра фильмов на законных источниках.
Kotlin, Jetpack Compose, Material 3, Media3 ExoPlayer.

## Что умеет

**Каталог** (данные The Movie Database)
- подборки: в тренде, популярные, сейчас в кино, лучшие, скоро;
- поиск по названию с подгрузкой при прокрутке;
- карточка фильма: кадр, постер, рейтинг, жанры, длительность, описание, актёры;
- кнопка «Трейлер» открывает трейлер в YouTube;
- кнопка «В открытом доступе» ищет этот фильм в разделе «Бесплатно».

**Бесплатно** (Internet Archive)
- фильмы в общественном достоянии: художественные, нуар, фантастика и ужасы, немое кино, мультфильмы;
- поиск по названию;
- просмотр во встроенном полноэкранном плеере, выбор версии файла.

**Настройки**: ключ TMDB и язык описаний (русский, украинский, английский).

## Сборка

### Android Studio
1. Откройте папку проекта в Android Studio (Koala или новее).
2. Дождитесь синхронизации Gradle.
3. Run ▶ на телефоне или эмуляторе (Android 7.0+).

APK без Android Studio: `./gradlew assembleRelease`, файл появится в
`app/build/outputs/apk/release/`. Нужен JDK 17 и Android SDK (путь в `local.properties`
как `sdk.dir=...` или в переменной `ANDROID_HOME`).

### GitHub Actions
Если загрузить проект в репозиторий на GitHub, workflow `.github/workflows/build.yml`
соберёт APK автоматически. Готовый файл будет во вкладке Actions → последний запуск → Artifacts.

## Ключ TMDB

Каталогу нужен бесплатный ключ:
1. Зарегистрируйтесь на https://www.themoviedb.org.
2. Откройте Настройки → API и запросите ключ (тип: Developer, личное использование).
3. В приложении: Настройки → вставьте «API Key» (v3) или «API Read Access Token» (v4) → Сохранить.

Раздел «Бесплатно» работает и без ключа.

## Структура

```
app/src/main/java/com/kinozal/app/
  KinozalApp.kt            контейнер зависимостей
  MainActivity.kt          навигация и нижняя панель
  data/                    TMDB, Internet Archive, настройки (DataStore)
  ui/catalog/              каталог TMDB и карточка фильма
  ui/free/                 бесплатные фильмы и их карточка
  ui/settings/             настройки
  player/PlayerActivity.kt полноэкранный плеер ExoPlayer
```

Этот продукт использует TMDB API, но не одобрен и не сертифицирован TMDB.
